# Niki

**Niki** is the core forensic parser engine of the
[Strategos](https://strategos.au) Suite — professional forensic
investigation platform.

Niki ingests and parses digital forensic exhibits across a wide range
of device types and formats, producing structured, verified artifact
records with full chain of custody integrity for use across the
Strategos Suite.

## Install

pip install niki
